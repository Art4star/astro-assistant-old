# Астрологічний асистент v3 — персональні цілі та теми

## НОВА КЛЮЧОВА ФУНКЦІЯ: Система особистих тем

Це перетворює асистента з "загального астро-календаря" на "особистий стратегічний радник".

Користувач задає свої актуальні теми один раз. Асистент:
1. Знаходить найкращий час для кожної теми в році і в поточному місяці
2. Будує звіт тільки навколо активних тем
3. Коли тема виконана — прибирає її і перефокусовується

## `manage_goals.py` — CLI для управління темами

```bash
# Показати всі активні теми
python manage_goals.py list

# Додати нову тему інтерактивно
python manage_goals.py add

# Позначити як виконану
python manage_goals.py done role_change

# Відкласти (не прибирати, але не показувати)
python manage_goals.py pause buy_car

# Змінити пріоритет
python manage_goals.py priority buy_car 1

# Показати виконані
python manage_goals.py history
```
