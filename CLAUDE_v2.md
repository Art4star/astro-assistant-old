# Астрологічний асистент v2 — оновлені інструкції для Claude Code

## КРИТИЧНА ЗМІНА КОНЦЕПЦІЇ

**Було:** календарна сітка з оцінками по кожному дню (+3, +5 тощо)
**Стало:** наративний місячний звіт у стилі живого астролога

Ніяких клітинок. Ніяких числових шкал на екрані. Тільки чіткі **вікна дій** із конкретними рекомендаціями по темах.

---

## Архітектурна зміна: два шари

### Шар 1 — розрахунок (залишається як є)
`engine/calculator.py` і `engine/interpreter.py` — без змін. Вони рахують позиції планет, аспекти, VOC, фази. Це внутрішні дані.

### Шар 2 — синтез (новий модуль)
`engine/synthesizer.py` — **новий модуль**. Бере сирі дані за місяць і перетворює їх у наративні блоки:
- Знаходить кластери схожих днів → формує "вікна" (діапазони дат)
- Визначає головну астрологічну тему місяця
- Генерує текстові блоки по кожній сфері

## Новий HTML шаблон — `templates/report.html`

Самодостатній HTML. Темна тема. Без зовнішніх JS бібліотек (тільки Google Fonts).

### Структура сторінки (зверху вниз):

---

### 1. HEADER

```
[Ім'я] · [Місяць Рік]
```
- Ім'я: білий великий шрифт
- Місяць: золотий акцент (`#f59e0b`)
- Підзаголовок: знак і позиція натального Сонця (маленький текст)

---

### 2. БЛОК — 🌟 ГОЛОВНА ТЕМА МІСЯЦЯ

```
🌟 ГОЛОВНА ТЕМА ТРАВНЯ 2026
"[title]"

[Ім'я] в цьому місяці:
• [bullet 1]
• [bullet 2]

Основні теми:
• [theme 1]
• [theme 2]
• [theme 3]

👉 Це місяць:
"[mantra]"
```

Стиль: велика секція, виділена рамкою з фіолетовим градієнтом зліва (`border-left: 4px solid #7c3aed`). Mantra — золотим кольором в лапках.

---

### 3. БЛОК — 📅 КЛЮЧОВІ ФАЗИ МІСЯЦЯ

Таблиця 2 колонки: **Період | Тема**

```
| 1–7 травня   | уповільнення, не форсувати    |
| 8–16 травня  | найсильніше вікно для дій     |
| 17–22 травня | перевірка емоцій              |
| 23–31 травня | стабілізація і закріплення    |
```

Стиль таблиці: без зовнішніх рамок, рядки чергуються темним фоном, ліва колонка жирна.

---

### 4. БЛОКИ ПО СФЕРАХ

Кожна сфера — окрема картка. Порядок карток:

1. 💼 Переговори / Керівництво / Вплив
2. 💰 Фінанси / Покупки / Рішення
3. 🚀 Нові починання
4. 🧘 Здоров'я / Відновлення
5. 🏡 Переїзд / Житло *(якщо є релевантні вікна)*
6. 🚗 Документи / Бюрократія *(якщо є релевантні вікна)*

**Структура кожної картки:**

```
[emoji] [НАЗВА СФЕРИ]
━━━━━━━━━━━━━━━━━━━━━━

🔥 [дати найсильнішого вікна]
Ідеально для:
• [пункт 1]
• [пункт 2]
Твоя енергія: [1-2 слова через кому]
👉 Важливо: [одне практичне правило]

🟢 [дати другого вікна]  *(якщо є)*
[коротший опис]
```

Стиль картки:
- Фон: `#161b22` (трохи світліший за основний)
- Рамка зверху: 3px кольорова лінія (різна для кожної сфери):
  - Переговори: синій `#3b82f6`
  - Фінанси: золотий `#f59e0b`
  - Нові починання: зелений `#22c55e`
  - Здоров'я: бірюзовий `#06b6d4`
  - Житло: пурпурний `#a855f7`
  - Документи: сірий `#6b7280`
- 🔥 — для найсильнішого вікна (score > 6)
- 🟢 — для хорошого вікна (score 3-6)

## Telegram формат (send_telegram.py)

Для Telegram — скорочена версія звіту (не весь HTML):

```
🌟 [Ім'я] · Астро-звіт: Травень 2026

Тема місяця: "[title]"

📅 Ключові вікна:
🔥 Переговори: 8–10, 14–16
💰 Фінанси: 11–15, 24–27
🚀 Нові починання: 9–16
🧘 Відпочинок: 1–4

⚠️ Обережно: 5–7, 19–21

🌟 Найсильніший день: 14 травня

👉 Повний звіт: ~/output/reports/2026-05-report.html
```

Відправляти ОДНИМ повідомленням на початку місяця.

## generate_report.py — оновлення

```bash
# Місячний звіт (основний)
python generate_report.py --type month --year 2026 --month 5
# → output/reports/2026-05-report.html

# Денний брифінг (коротко, для cron 8:00)
python generate_report.py --type today
# → відправляє в Telegram текстом (не HTML)

# Найкращі дні для конкретної задачі
python generate_report.py --type best --activity finance --days 30
# → відповідь текстом: "Фінанси: найкращі вікна наступні 30 днів: 11–15, 24–27"
```

## Тест-перевірка якості

Після генерації перевір що HTML звіт:
- [ ] НЕ містить числових оцінок (+3, +5) у видимій частині — тільки всередині tooltip або взагалі прибрати
- [ ] Містить конкретні діапазони дат ("8–10 травня"), не окремі дні
- [ ] Кожна сфера має мінімум одне "вікно дій" і одне "уникати"
- [ ] Є блок "Найсильніший день" із конкретною датою
- [ ] Є підсумкова таблиця
- [ ] Немає календарної сітки
